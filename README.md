# Hackathon Fall 2026
This is a repo for our group's Fall 2026 Hackathon, with a Python file for cleaning a dataset and an R file for running a regression and creating  a regression table The nyc_access csv is uncleaned, the nyc_access_clean csv is cleaned and ready for analysis, the Jupyter file is the cleaning code, and the Rmd file is the regression and html creation code.
